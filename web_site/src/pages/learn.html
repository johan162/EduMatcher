Textbooks describe order books. EduMatcher lets you place an order, watch it rest, get hit, and appear in the audit trail — and then read exactly which lines of code did it.

Concepts, then code

Every chapter opens with learning objectives and builds from the finance idea to the data structure to the source file that implements it.

Break it on purpose

Halt a symbol, trip a circuit breaker, kill a process, replay the audit trail. A venue that can be broken safely is one you can understand.

For instructors

A class-sized market,
on demand

An exchange that is never empty

A single container runs {{F_SIM_TRADERS}} AI traders across {{F_SIM_SYMBOLS}} symbols, with a hidden true value, headlines and rumours. Students trade next to the bots and see prices react to news they can read.

Accelerated time

Compress a trading day into minutes so a lecture can include an opening auction, a news shock and a close.

One URL per student

API keys map to participants and roles. Give each student a trader key; put TapeDeck on the projector; keep the Operator Dashboard on your own screen.

Grade the evidence

The audit trail and clearing P&L record exactly what each participant did — perfect for post-session debriefs and assignments.
