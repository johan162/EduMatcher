The system

Pick how you want to run it

A clean exchange

recommended

Docker or Podman. Starts the exchange and the six web applications with a bundled configuration — you are the only trader.

$curl -fsSL https://raw.githubusercontent.com/johan162/EduMatcher/main/deployment/curl/install.sh | bash

Then cd ~/.edumatcher and run ./edumatcher.sh shell.

A living market

for classes

The same, plus 300 symbols and 100 AI traders trading on hidden values, news and rumours.

$curl -fsSL https://raw.githubusercontent.com/johan162/EduMatcher/main/deployment/curl/install.sh | bash -s -- --sim

Then cd ~/.edumatcher-sim.

Python package

PyPI

Python 3.13+. Installs the engine, gateways and terminal tools; the browser apps are container images.

$pipx install edumatcher && pm-setup

Pin this release: pipx install edumatcher==0.51.5

From source

hackers

Clone, install with Poetry and run the test-suite — the route for contributors.

$git clone https://github.com/johan162/EduMatcher && cd EduMatcher && poetry install

See the Development Practice chapter.

Once it is running: Trading GUI :8093 · TapeDeck :8090 · Order Book :8094 · Dashboard :8095 · Log Console :8091 · Config Builder :8092 · REST docs :8080/docs. The Trading GUI needs an API key — ./edumatcher.sh shell pm-config-show -a prints them.
