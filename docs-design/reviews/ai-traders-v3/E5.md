# E5 — news display

Device, `s150-nominal`: engine, `pm-market-sim`, `pm-api-gwy` `desk` (trader
key) and `dashboards` (read-only key), and an observer holding the market-data
WebSocket, polling `GET /api/v1/news` with the read-only key every 100 ms,
and running `pm-ticker`'s receive loop. One `pm-news inject` (a rumour).

| Display path | Time from command to headline |
|---|---|
| API market-data WebSocket (`news` channel) | 0.531 s |
| `GET /api/v1/news` (read-only key — TapeDeck's path) | 0.581 s |
| `pm-ticker` socket | 0.532 s |

About 0.5 s of each is `pm-news` start-up. TapeDeck polls its bridge's
`/api/news` once a second, so ≤ 1.6 s; the trading GUI applies the WebSocket
event directly. Criterion (within 2 s): met.

GUI tests: trader-gui 471 vitest + typecheck; terminal-gui 690 vitest +
typecheck (container, `npm ci`).

Deviation: TapeDeck reads news through the bridge's REST proxy rather than
CALF (no CALF protocol change for a few headlines a day).
