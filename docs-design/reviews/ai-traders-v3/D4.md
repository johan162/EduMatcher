# D4 / D6 — `pm-market-sim` and ADMIN visibility

Device, `s150-nominal`, engine + `pm-market-sim` + scripted session.

| Check | Result |
|---|---|
| Steps only in CONTINUOUS; pauses outside it | `sim.state` RUNNING ↔ PAUSED with the session |
| Restart continuity | saved state reloaded; `seq` continued 5 → 6, values unchanged |
| Engine restart | re-asks the session until it answers (code path; not run live) |
| `pm-market-sim --status --id OPS01 --top 3` | state + widest mid/value gaps |
| Commands from a non-ADMIN participant | refused (unit test `test_commands_need_an_admin`) |
| `GET /api/v1/admin/sim`, WS `/api/v1/admin/sim` | values for ADMIN; 403 for TRADER and read-only keys (unit tests) |

Plan deviation: no `sim_time`/`speed` fields and no `--speed` flag. The model
follows the engine's phases and accrues a day's variance over the continuous
phase as the engine reports it (from its start to the scheduler's countdown),
so a day compressed with `pm-scheduler --speed` moves as much as a real one.
