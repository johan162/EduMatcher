# C3 — AI traders through `pm-alf-gwy`

20 agents, budget 40, `s150-nominal`; `pm-alf-gwy` killed (`kill -9`) at
50 s and restarted 5 s later.

| Measure | Result |
|---|---|
| All 20 sessions back | 25.2 s after the kill |
| Positions after reconnect = engine | 20/20 |
| Rejects | 0 |
| Throughput | 39 actions/s |
| Order types | all 12 type/TIF combinations |

Plan gaps found and fixed:

- The engine frees a gateway ID only after 3 missed heartbeats at 60 s =
  180 s, so "reconnect within 30 s" was impossible. `pm-alf-gwy` now
  heartbeats the engine every 5 s (expiry 15 s).
- Per-session subscribe-then-request lost replies (`SYMBOLS_NOT_READY`);
  `pm-alf-gwy` now subscribes every gateway-scoped family by prefix at
  start-up.
- `.gitignore`'s `alf_client` (a C example binary) also hid
  `src/edumatcher/alf_client`; negation added.
