# C4 — sharded workers and supervisor

`pm-ai-swarm`, 500 agents in 3 workers, 600-participant config.

| Measure | Result |
|---|---|
| All 500 sessions up | 12 s after launch |
| Worker `kill -9` | that worker back in 2.0 s; the others undisturbed |
| `SIGTERM` | exit 0 in 0.3 s; 0 sessions and 0 processes left |

Observation: the budget controller starts from one action per decision
(real: 0.1–0.4) and corrects by at most +22 % per 10 s, so the first minute
runs below budget.
