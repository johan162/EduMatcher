# D5 — value strategy and market-maker anchoring

Container. `s150-nominal`, `pm-engine`, `pm-alf-gwy`, `pm-market-sim`,
`pm-ai-swarm` with the example's `swarm.yaml` (20 agents, 30 % value
presets, budget 40, every agent on all 150 symbols), with or without
`pm-mm-bot --all-symbols --strategy passive --gap 0.20 --qty 200`.
Continuous trading of 3600 s with the session countdown, so one hour is one
compressed model day (σ of a whole day accrues in the hour — a harder test
than real time). Mid and value of every symbol sampled every 10 s; the first
300 s are warm-up.

| Set-up | RMS ln(mid / V) | Notes |
|---|---|---|
| Passive market maker, not anchored (aborted at 7 min) | 2.2 % → 3.8 %, rising | The bot refills its quotes around its own mid; informed orders cannot move the price |
| No market maker | **1.41 %** | median \|gap\| 0.74 %; the RMS comes from thin books (p90 spread ~4 %) |
| Anchored `--anchor-sim 0.3`, first version | 1.3–2 % | Mid re-derived from the book at every update: a fixed blend of value and stale orders. Fixed |
| Anchored `--anchor-sim 0.3`, fixed | **0.52 %** (44 min; the container was reclaimed) | median \|gap\| ~0.1 % |
| The `ai-swarm` profile's maker (anchored 0.3, 5 s re-issue, 3-tick / 20 s fade, 15-tick drift), full hour | **0.54 %** — pass | |

Other criteria, the full hour:

| Criterion | No market maker | `ai-swarm` profile's maker |
|---|---|---|
| Daily volatility of prices within ±25 % of model σ | price/model 1.335 (value/model 1.148 in the same window) | **price/model 1.197** — pass (price/value 1.04) |
| Return kurtosis > 3 | 6.22 — pass | **9.81** — pass |
| Positive \|r\| autocorrelation, lags 1–10 | positive to lag 8, then −0.016, −0.032 | lag 1 0.374, lags 2–10 −0.036…−0.003 — **not met** |

Volatility clustering beyond one minute is not there: the model has no
stochastic volatility, only the intraday activity curve and jumps, and an
hour is a short sample. The lag-1 value probably comes from the market maker
re-quoting in steps. A GARCH-like term in the model would be the change if
this matters for teaching.

Bugs found and fixed:

- `pm-mm-bot --anchor-sim` (mine, D5): anchored only on book updates, so a
  quiet book never followed the value; and the passive pricer reset the mid
  from other traders' (often stale, one-sided) levels at every update. Now,
  once a value is known, the value sets the mid at every model step and the
  book only feeds the passive plan.
- The `ai-swarm` profile's market maker is now anchored (`--anchor-sim 0.3`)
  and its agents trade every symbol.
