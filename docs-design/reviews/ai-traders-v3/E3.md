# E3 — `pm-news`

Device, `s150-nominal`, engine + `pm-market-sim` + a `sim.value`/`news.event`
subscriber.

| Check | Result |
|---|---|
| `inject --symbol AAPL --impact 0.0953` | headline 0.53 s after the command (CLI start-up); AAPL value +10.0 % |
| Sector rumour (TECH, impact −0.05, cred 0.4) | no value move |
| `confirm` it | MSFT −2.2 % (= β_s 0.45 × −5 %) |
| `confirm` as `TRADER01` | refused, exit 1 |

Bug found in E6 and fixed: `pm-news play` only fired the steps of a phase it
saw *start*, so a scenario started during continuous trading never ran. It
now asks the engine for the current phase, which counts from the start of
the play.
