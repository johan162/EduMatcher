# EduMatcher — Summary of Changes (Aug 30 – Sep 6, 2026)

Covers six release cycles: v0.27.2 through v0.32.1.

## Order and trade identity correctness

The largest single piece of work was the v0.28.0 release (Sept 1), which was a genuine breaking-change release. Trade IDs became durable `run_seq-counter` identifiers (e.g. `000042-000000001`) that survive engine restarts, replacing the old numeric IDs. The REST `client_order_id` field was replaced everywhere by `client_tag`, and cancel/amend requests gained a parallel `request_tag` for correlation. This rippled through REST, WebSocket, ALF, CALF, drop-copy, clearing, and statistics, since trade IDs became the sole database key — existing clearing and statistics databases had to be recreated, as they could not be migrated.

Alongside this, canonical `reject_code` values were added so order ACKs, REST errors, and ALF `ACK`/`ERR` messages report rejections consistently through a single centralized reject funnel in the engine. Explicit cancel reasons were added for rejected cancels and circuit-breaker-triggered cancels (v0.29.1).

A related persistence effort (v0.29.0) made DAY orders and market-maker quote legs survive same-day engine restarts, by persisting and bumping a dedicated run-sequence file before GTC recovery. A follow-up fix in v0.32.0 addressed a bug where partially-filled MM quote legs weren't being removed from the book after replacement.

## Risk controls and fill reporting

v0.30.0/v0.31.0 added per-symbol pre-trade risk limits: `max_order_qty` and `max_order_value`, with supporting updates to `pm-config-gen` and the config GUI. The same release cycle added a `liquidity_flag` (`MAKER`/`TAKER`) to private fill notifications, threaded through the engine, ALF, REST/WebSocket, and drop-copy paths.

## Market-maker bot

v0.32.0 gave `pm-mm-bot` YAML configuration file support with command-line overrides, and a pluggable pricing-strategy selection mechanism (with `symmetric` as the default strategy). It also fixed a tick-decimal registration bug. In the still-unreleased work that followed 0.32.0 (now version 0.32.1), the bot was extended to support market-making across multiple symbols from a single instance, and two performance fixes were added: an index to avoid linear search when replacing quote legs, and an index to avoid a linear sweep when canceling orders on gateway disconnect.

## Performance and infrastructure

Hot-path order validation was trimmed by skipping the validating order builder, and order-ID generation switched from `uuid4` to `os.urandom` for lower overhead. An unnecessary cast was removed from a hot path, and matching-engine performance was reprofiled, with per-test benchmarks now skipped by default in both CI and normal local test runs.

Infrastructure work included repeated fixes to the GitHub Actions frontend container build (an npm Arborist dependency-resolution/deduplication bug recurred across several releases), Multipass VM tooling improvements for macOS (including a restart-recovery utility script), and a reduction in CI load — full checks now run only on merge to `main` and on pull requests rather than on every push.

## Documentation and training

Documentation and training material saw very heavy, sustained investment — by file count, comparable to the code changes themselves (68 test files, 36 user-guide files, 21 training files touched). Highlights:

- Added the `require_mm_seed_quotes` configuration setting and `--no-mm-seed-quotes` flag for `pm-config-gen`, letting order books start genuinely empty of market-maker seed quotes; added twelve bundled `-nomm` example configurations.
- Renumbered all training chapters to a consistent three-digit prefix scheme.
- Added EPUB3 editions of both the user guide and the training material.
- Reworked installation documentation to make container-based installation the primary, recommended setup path (previously bare-metal instructions were primary).
- Significantly rewrote the "your first trade" concept documentation and the system-trading-verification design document to match current implementation behavior.
- Normalized console prompt strings across the user guide and training material, and corrected several stale or drifted command-line examples.

## By the numbers

347 files changed, roughly 40,000 lines added and 4,700 removed since the baseline commit before Aug 30. The most-touched areas were tests (68 files), `docs/user-guide` (36), and `docs/training` (21), followed by the trader-gui web app, docs-exchange-intro, and core engine/model/config-gen source.
