# Choose your book

Use the book that matches your next task:

- **Participant Guide** for trading, orders, market making, and participant-facing tools.
- **Operator's Guide** for installation, configuration, running a market, and recovery.
- **Reference Manual** for command, configuration, process, and data-store details.
- **Protocols and Clients** for external protocols, message formats, and client examples.
- **Architecture and Developer Guide** for system design, development, verification, and releases.
- **Training Guide** for a structured course through trading and operating the exchange.

Start with the Participant Guide if you are learning to trade. Start with the Operator's Guide if you are deploying an exchange.
